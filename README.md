# Revit AI Assistant - Releases & Installation
# מאגר קבצי התקנה - עוזר AI לרוויט

<div dir="rtl" align="right">

ברוכים הבאים למאגר הרשמי של קבצי ההתקנה וההפצה עבור **Revit AI Assistant**.

תוסף זה משלב עוזר בינה מלאכותית מתקדם מבוסס מודלי שפה מובילים (**Google Gemini**, **OpenAI**, **Anthropic Claude**) ישירות בתוך ממשק Autodesk Revit, ומאפשר אוטומציה של מודלים, תשאול חכם, יצירת אלמנטים והרצת קוד C# בזמן אמת.

---

### 📦 הורדת קובץ ההתקנה העדכני

- **[לחץ כאן להורדת קובץ ההתקנה: Revit_AI_Assistant_V0.1.exe](../../releases/latest/download/Revit_AI_Assistant_V0.1.exe)**
- **גרסה נוכחית:** `V0.1`
- **גרסאות Revit נתמכות:** `2021`, `2022`, `2023`, `2024`, `2025`, `2026`, `2027`.

---

### 🚀 הוראות התקנה

1. **סגור את תוכנת Revit** במידה והיא פתוחה.
2. הורד והפעל את קובץ ההתקנה `Revit_AI_Assistant_V0.1.exe`.
3. עקוב אחר הוראות אשף ההתקנה (ההתקנה פורסת אוטומטית את התוסף לתיקיות ה-Addins של הגרסאות המותקנות במחשבך).
4. פתח את Revit – בלשונית החדשה **AI Assistant** ב-Ribbon יופיע כפתור ההפעלה של העוזר.
5. בהפעלה הראשונה, פתח את חלון ה-**Settings** והגדר את מפתח ה-API הרצוי (Google Gemini / OpenAI / Anthropic).

---

### ✨ תכונות עיקריות בגרסה זו

- **תמיכה מלאה במודלים החדשים ביותר:**
  - **Google Gemini:** `gemini-3.8-flash`, `gemini-3.7-flash`, `gemini-3.6-flash`, `gemini-3.5-flash`, `gemini-2.5-pro` ועוד.
  - **OpenAI:** `gpt-4o`, `gpt-4o-mini`, `o3-mini`, `o1`, `gpt-4.5-preview` ועוד.
  - **Anthropic Claude:** `claude-3-7-sonnet`, `claude-3-5-sonnet`, `claude-3-5-haiku`, `claude-3-opus`.
- **עדכון דינמי של רשימת המודלים בעליית Revit** מול ה-API של כל הספקים.
- **תמיכה מובנית בריבוי שפות:** עברית (כולל יישור RTL ומענה מלא במשפטים טבעיים), אנגלית, ספרדית ורוסית.
- **הרצת סקריפטים וקוד C# ברוויט** עם תיקון שגיאות אוטומטי (Auto-Fix).
- **תמיכה בריבוי טאבים של שיחות (Multi-Chat Tabs).**
- **תמיכה בחיפוש בזמן אמת באינטרנט וב-MCP Bridge.**
